Proyecto 01 · Redes y ciberseguridad

Firewall y segmentación de red

Diseño de una infraestructura de red organizada y protegida mediante un firewall central, diferentes segmentos y políticas de comunicación.

01 / Visión general

Descripción del proyecto

El objetivo de este proyecto es desarrollar una infraestructura de red de laboratorio que permita comprender cómo se organiza y protege una pequeña red empresarial. Para ello se utilizará OPNsense como solución de firewall, creando diferentes segmentos virtuales para separar los dispositivos según su función. Esta separación permite estudiar cómo controlar las comunicaciones y aplicar diferentes políticas de acceso.

02 / Objetivos

Objetivos técnicos

  • Diseñar una arquitectura de red organizada.
  • Configurar un firewall central mediante OPNsense.
  • Crear diferentes segmentos de red mediante VLAN.
  • Definir políticas de acceso siguiendo el principio de mínimo privilegio.
  • Comprobar la conectividad entre los diferentes segmentos.
  • Documentar la arquitectura y las pruebas realizadas.
03 / Arquitectura

Diseño de infraestructura

La arquitectura estará formada por un firewall central que gestionará las comunicaciones entre las diferentes redes.


INTERNET / RED DE PRUEBAS | | [OPNsense] | SWITCH VIRTUAL | ------------------- | | | USUARIOS SERVIDORES ADMIN VLAN 10 VLAN 20 VLAN 30

Cada segmento tendrá una función específica y unas políticas de comunicación documentadas.

04 / Desarrollo

Fases del proyecto

  • Preparación del entorno virtualizado.
  • Instalación de OPNsense.
  • Diseño de la estructura de red.
  • Configuración de segmentos.
  • Definición de reglas de acceso.
  • Pruebas de conectividad y documentación.
Tecnologías

Stack tecnológico

  • OPNsense
  • VirtualBox
  • VLAN
  • TCP/IP
  • Redes virtuales
Entregables

Resultado esperado

  • Diagrama de red.
  • Documentación técnica.
  • Matriz de reglas.
  • Pruebas de conectividad.
  • Conclusiones técnicas.

Proyecto 02 · Sistemas y servidores

Servidor Linux con Docker

Creación de una infraestructura basada en Linux y Docker para desplegar y administrar diferentes servicios de manera organizada.

01 / Visión general

Descripción del proyecto

Este proyecto consiste en preparar un servidor Linux capaz de ejecutar diferentes aplicaciones mediante contenedores Docker. La virtualización mediante contenedores permite mantener los servicios organizados, independientes y relativamente sencillos de desplegar. El objetivo es construir una infraestructura reproducible y documentada que facilite su mantenimiento.

02 / Objetivos

Objetivos técnicos

  • Preparar un servidor Linux.
  • Instalar y configurar Docker.
  • Gestionar servicios mediante Docker Compose.
  • Configurar almacenamiento persistente.
  • Documentar los despliegues.
  • Estudiar procedimientos de mantenimiento y recuperación.
03 / Arquitectura

Diseño del servidor

SERVIDOR LINUX | DOCKER ENGINE | DOCKER COMPOSE | ---------------- | | | WEB DATABASE MONITORING | | | ---------------- | ALMACENAMIENTO PERSISTENTE

Los servicios estarán organizados mediante configuraciones reproducibles y documentación específica.

Fases del proyecto
